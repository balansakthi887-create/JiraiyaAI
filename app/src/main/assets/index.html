⚡ E. Voice Commands & Device Control

            

              

                
1. Search

                
Say "Search Google for..." or "Google-la ... search pannu". Works in both WebView and Android APK.

              

              

                
2. Applications (`PackageManager`)

                
Say "Open YouTube", "Open WhatsApp", or "Open Settings". Requires the native Android APK (`MainActivity.kt` + `` in `AndroidManifest.xml`). Android does not permit ordinary apps to force-stop other apps; saying "Close YouTube" returns you to Maxter J.

              

              

                
3. Device Controls (Flashlight, Volume, Brightness)

                
Hardware Flashlight (`CameraManager`), Volume (`AudioManager`), and System Brightness (`Settings.System.SCREEN_BRIGHTNESS` with `WRITE_SETTINGS` permission) execute natively inside the Android APK.

              

              

                
4. Optional Floating Character Overlay (`SYSTEM_ALERT_WINDOW`)

                
Displays your existing Maxter J character over other apps when enabled in the Android APK.
